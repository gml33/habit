# Hourly Check-in Frontend

## Requisitos
- Node.js 18+

## Configuracion
```bash
npm install
```

## Variables de entorno
Crear `.env` si necesitas cambiar la API:
```
VITE_API_BASE_URL=http://localhost:8000
```

## Desarrollo
```bash
npm run dev
```

Abri `http://localhost:5173/checkin?user_id=marce&ts_hour=2026-01-09T14:00:00-03:00&token=changeme`
